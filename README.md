## macOS 原生版 1.2.0

上下翻页时，MacDV 静音预载下一条，等首帧解码后才移动当前画面；即使网络慢，也不会为了切页先清空播放器。触控板、鼠标滚轮和 ↑/↓ 都可翻页，系统「减弱动态效果」开启时不播放滑动动画。

**安装**：从 [MacDV 发布页](https://github.com/275556968/MacDV/releases) 下载适配处理器的 macOS ZIP。退出旧版，解压并将 **MacDV.app** 拖入「应用程序」。macOS 13+；预编译包为 ad-hoc 签名，未经过 Apple 公证。源码构建运行 `./build_app.sh`，生成可独立打开的 App，不需要 Node.js 或额外的网页播放器。[安装、快捷键与回归测试说明](SMOOTH.md)

## ✨ 核心亮点

### 📺 1. 横屏精选视频流优先
- 深度锁定官方横屏精选推荐通道（`/jingxuan`）与综合推荐通道，内置宽高比智能识别与过滤；
- 专为 PC 宽屏显示器、高刷电竞屏打造，告别竖屏黑边，大幅提升观影沉浸感。

### 🚀 2. 始终最高清晰度优先 (1080P/超清/4K)
- 自动解析每个作品的所有清晰度与比特率码率流，优先选用最高清晰度；
- 支持 1080P、2K、4K 高清流无缝硬件加速解码播放。

### 💡 3. 长视频播放防屏幕休眠
- 深度集成 Windows 电源管理系统（`PowerSaveBlocker` / `SetThreadExecutionState`）；
- 视频播放时自动阻止 Windows 屏幕熄灭、变暗或进入睡眠；暂停播放后立即智能释放，节能安全。

### ⏩ 4. 键盘左右方向键快进与快退
- **`→` 右方向键**：快速前进（默认 10 秒）；
- **`←` 左方向键**：快速后退（默认 10 秒）；
- **支持连续按键累加**：快速敲击 3 次即快进 30 秒，无需反复缓冲；
- **原生居中毛玻璃 HUD 指示器**：屏幕中央实时浮现快进秒数、当前时间进度与 mini 进度条；
- **步长秒数可自由定制**：在设置中提供 5秒、10秒、15秒、30秒预设及 1~180 秒自定义调节。

### 🪟 5. 全屏纯净观影模式（快捷键 `H`）
- 一键隐藏画面上的所有操作按钮、作者信息、标题和进度条，全屏幕仅保留纯净视频画面；
- **碰触四边临时唤出**：鼠标移到窗口顶部、底部或左右边缘时临时显示界面，2.5 秒无操作自动回到纯净模式，不会永久退出（可在设置中关闭）；
- **智能联动恢复**：进入全屏可自动进入纯净模式，退出全屏时按键与控件自动恢复，体验优雅。

### 🖱️ 6. 滚轮与触控板精准防连跳
- 针对 Windows 鼠标滚轮与高精度触控板优化阻尼手势，每次物理轻扫手势仅切换单个视频，彻底杜绝一次划过多个视频的失控现象。

### 🛡️ 7. 第三方弹窗彻底免疫
- 内置 DOM 拦截与 URL Scheme 过滤机制，彻底阻断类似 `bitbrowser://` 等烦人的系统弹窗探针。

### 🐟 8. 摸鱼与日常使用优化
- **窗口置顶 (快捷键 `T`)**：小窗浮动，始终保持在其他窗口之上；
- **透明度无极调节**：支持 25%~100% 窗口半透明调节，办公摸鱼神器；
- **一键快捷静音 (快捷键 `M`)**；
- **倍速播放**：右上角倍速按钮可切换 0.5X / 0.75X / 1.0X / 1.25X / 1.5X / 2.0X / 3.0X，也可按 `[` / `]` 快速增减，速度会被记住并应用到后续视频；
- **半透明评论抽屉 (快捷键 `C`)**：右侧平滑滑出热门评论列表；
- **扫码与 Cookie 登录**：支持官方扫码登录与 Cookie 导入，自动同步个性化推荐。

### 🔁 9. 看过的视频自动去重
- 播放过的作品会按 `aweme_id` 记入本机观看记录（最多 3000 条），**刷新、切频道、重启客户端都不会再重复推荐**；
- 获取推荐流时自动剔除「已看过 / 队列中已有 / 同批次重复」的作品，一批刷完都是老视频时会自动再拉两批；
- 设置中可随时关闭去重，或一键清除观看记录；记录只保存在本机 `localStorage`，不上传任何服务器。

### 👤 10. 点击头像进入博主主页
- 点击右侧**作者头像**或**作者昵称**即可打开博主空间：头像、昵称、签名、粉丝数 / 作品数一览；
- 主页以卡片网格展示其全部作品（封面、时长、点赞数、清晰度，竖屏作品带角标），**滚动到底部自动加载**下一页，首屏不满一屏时也会自动补足；
- **点击任意作品立即播放**，随后下滑即可连续观看该博主的全部作品（播放中自动加载后续分页）；
- 播放博主作品时左上角显示 **「← 返回推荐流」** 悬浮按钮，点击或按 `Esc` 即可回到进入空间前的推荐流队列与播放位置；
- 竖屏作品播放时自动切换为**比例模式**（不裁切画面），按 `S` 仍可手动切换；打开空间期间主界面快捷键自动停用，`Esc` 或点击遮罩关闭。

### 💬 11. 弹幕
- 自动加载当前视频的抖音弹幕，在画面上方滚动显示；按 32 秒分段按需拉取并提前预取，切回看过的视频不会重复请求；
- 弹幕与视频**严格同步**：暂停即停、倍速同步加速、拖动进度或循环重播后从新位置继续；
- 智能分轨防重叠，放不下的弹幕自动略过，不会文字叠文字；
- 右上角 **「弹」** 按钮或快捷键 `D` 一键开关；设置中可调**不透明度、显示区域（1/4 屏 ~ 全屏）与字号**。

| :--- | :--- |

| **`S`** | 切换画面**铺满窗口 / 原始比例** |
| **`F`** / **双击画面** | 进入 / 退出**全屏模式** |
| **`M`** | 快速**静音 / 开启声音** |
| **`[` / `]`** | **降低 / 提高播放速度**（0.5X–3.0X，也可点右上角倍速按钮） |
| **`D`** | 显示 / 隐藏**弹幕** |
| **`C`** | 打开 / 关闭**半透明评论抽屉** |
| **`R`** 或 **`Ctrl + R`** | **刷新**当前视频推荐流 |
| **`T`** | 切换**窗口置顶 (Always on Top)** |
| **`Esc`** | 退出全屏 / 关闭弹窗及评论抽屉 |

## 📦 Windows 版本安装与运行

### 1. 直接运行绿色免安装版 (Portable)
已自动编译生成单文件免安装绿色版：
- 文件路径：`dist/WinDV-1.0.0-Portable.exe`
- 双击即可直接运行，无需安装，无任何系统残留。

或者直接使用解包目录绿色版：
- 文件路径：`dist/win-unpacked/WinDV.exe`

### 2. 从源码运行与打包

环境要求：Windows 10/11，Node.js 18+ (推荐 Node 20/24)。

```bash
# 1. 安装依赖
npm install

# 2. 本地开发启动运行
npm start

# 3. 运行自动化端到端测试
node scripts/test-app-e2e.js

# 4. 打包 Windows 绿色版与安装包
npm run dist
```
