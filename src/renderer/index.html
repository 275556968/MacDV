偏好设置 & 快捷键

摸鱼与窗口显示

窗口始终置顶 (Always on Top) 小窗模式下始终保持在其他窗口之上，快捷键 T
窗口透明度 无极调节窗口半透明度，适合摸鱼办公
100%

纯净观影模式 (仅保留视频画面)

启动时自动开启纯净模式 启动时自动隐藏所有操作按钮、标题与进度条
进入全屏时自动进入纯净模式 全屏沉浸观影，退出全屏自动恢复操作按钮

画质与播放

优先最高清晰度 (1080P/超清/4K) 自动解析最高分辨率与比特率码率流，大屏更清晰
启动时自动开启声音 (取消静音) 默认开启视频原声伴音，快捷键 M 可随时静音
视频播放时防止屏幕休眠 阻止 Windows 屏幕熄灭变暗；暂停后自动恢复

方向键快进 / 快退步长

步长选择 (左右方向键) 支持连续敲击键盘快速累加秒数

键盘快捷键一览

快捷键功能说明
→ (短按)视频快进（支持连续敲击累加秒数）
→ 或 鼠标右键 (长按)2倍速快放（松开即恢复正常播放）
← (左方向键)视频快退（支持连续敲击累加秒数）
Space (空格)播放 / 暂停切换
↓ 或 J切换到下一个视频
↑ 或 K切换到上一个视频
滚轮 / 触控板滑动精准阻尼切换视频（防连跳）
H纯净模式切换（一键隐藏/恢复全部界面按钮）
S切换画面铺满窗口 / 原始比例
F 或 双击画面进入 / 退出全屏模式
M快速静音 / 开启声音
C打开 / 关闭原生半透明评论抽屉
R 或 Ctrl+R刷新当前频道视频推荐流
T切换窗口置顶 (Always on Top)
Esc退出全屏 / 关闭弹窗及评论抽屉
